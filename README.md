# 🚀 Fedor Cheb — Персональный веб-сайт и портфолио

Современный, адаптивный и многоязычный веб-сайт-визитка, разработанный для презентации проектов по автоматизации, асинхронному программированию и Telegram-ботам.

🌐 **Живой сайт:** [https://fedorcheb.chebur.shop](https://fedorcheb.chebur.shop)

---

## 📋 Особенности проекта

- **📱 Полная адаптивность:** Отличный внешний вид на компьютерах, планшетах и мобильных устройствах (использована Grid/Flexbox верстка).
- **🌍 Мультиязычность (RU / EN / DE):** Мгновенное переключение языков без перезагрузки страницы прямо на клиенте (чистый JavaScript).
- **🎨 Тёмная тема в стиле Cyber/Tech:** Разработана с использованием блюра (`backdrop-filter`), аккуратных неоновых акцентов и плавной анимации.
- **💬 Интерактивные модальные окна:** Детальные карточки услуг и технологий открываются в плавающих окнах.
- **👥 Счетчик посещений:** Локальное отслеживание визитов пользователей (`localStorage`).
- **⚡ Высокая скорость работы:** Отсутствие тяжелых библиотек (чистый HTML5, CSS3, Vanilla JS).

---

## 🛠 Технологический стек

- **HTML5** — Семантическая разметка страницы.
- **CSS3** — Custom Properties (переменные), Flexbox, CSS Grid, Media Queries, Keyframes-анимации.
- **JavaScript (ES6+)** — Логика переключения языков, модальные окна, обработка событий.
- **SVG / Base64** — Встроенная легкая фавиконка и оптимизированная графика.
